# Semih_Gozubuyuk_Exams

This repository contains the weekly C# assignments and practice projects completed during the **InfoTech Academy** training program.

Each assignment is developed as an independent **.NET Console Application** and organized by training week. The primary goal is to reinforce Object-Oriented Programming (OOP) concepts through hands-on practice.

---

## Repository Structure

```text
Semih_Gozubuyuk_Exams
│
├── Week03/
│   ├── Odev01/
│   ├── Odev02/
│   ├── Odev03/
│   └── README.md
│
├── Week04/
├── Week05/
└── ...
```

Each **WeekXX** folder contains the assignments completed during that week of the training program.
